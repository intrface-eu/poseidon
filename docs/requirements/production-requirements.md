# Poseidon production requirements and verification matrix

Status: active baseline, 2026-09-07

This register turns the approved [production roadmap](../production-roadmap.md) into traceable requirements. It does not show that a requirement has passed. All entries start `Unverified`; only linked evidence reviewed by the named owner can change that status.

## Status and ownership rules

- `Unverified`: no accepted verification evidence exists.
- `Blocked`: a named input, permission, or decision is missing.
- `Verified`: the owner accepted the stated evidence against the frozen criterion.
- `Rejected`: evidence failed the criterion or the requirement was withdrawn through a recorded decision.
- The product owner controls scope and claims. Qualified site, ecology, acoustics, engineering, compliance, and manufacturing owners control decisions in their fields.
- `TBD` is a blocked decision, not permission to use a convenient value. Freeze each threshold before the applicable design freeze or held-out evaluation.
